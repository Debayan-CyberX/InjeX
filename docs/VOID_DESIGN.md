# InjeX / VOID — Experimental Monochrome

The redesign uses near-black neutral surfaces, silver and white typography, an acid-lime focus accent, and restrained red for actual threat states. Each section has a distinct composition: cinematic introduction, inspection console, experiment canvas, paired benchmark, classification field, event ledger, data observatory, technical blueprint, and editorial manifesto.

## Original chrome asset

Saved project asset: `frontend/public/images/void-chrome.webp` (1536 × 1024, approximately 84 KB). Generated with the built-in image generation tool, then encoded as WebP for delivery. The image is a decorative form study, not a detector visualization or live data. Pointer motion is a small transform, disabled for reduced-motion and coarse-pointer devices.

Final generation prompt:

ONLY black, charcoal, white, silver. No copper, no gold, no colors, no neon, no glow, no particles, no stars, no computer screens, no diagrams, no text, no letters, no logos, no watermark. All nine hash routes remain compatible with `/InjeX/` on GitHub Pages.
